Download the **Tweakerzzz-Setup-0.2.2-x64.exe** asset below. The source-code ZIP files are not the installer.

1. Close any older Tweakerzzz window.
2. Double-click the downloaded installer. It installs for your Windows account and creates desktop and Start menu shortcuts.
3. Open **Tweakerzzz** from either shortcut. Node.js, npm, a source checkout, and PowerShell launch commands are not required.
4. Open **Peripherals → Scan devices**, then select a device for matching recommendations. Use **Export device report** when reporting a recognition issue.

This is an **unsigned Windows x64 tester build**. Windows may show an unknown-publisher or SmartScreen notice; a verified-publisher signature is not included. Organization-managed policies can still require a signed build.

Hardware scanning and tweak detection are read-only. Review a plan before applying Windows preferences; use Restore center to undo supported changes. Peripheral recommendations are manual. Current DPI, polling rate, and camera modes are not measured. There is no promised FPS increase.

Uninstall through **Windows Settings → Apps → Installed apps → Tweakerzzz**. The app's saved profiles and restore backups are preserved when uninstalling. Keep those backups if you have applied tweaks.

`SHA256SUMS.txt` contains the installer checksum. The release workflow builds on Windows, verifies packaged files, and tests install, launch, shortcuts, and uninstall before publishing.
